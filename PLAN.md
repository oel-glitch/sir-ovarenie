# Басовое космическое сыроварение — план

Подарок другу-басисту. Настольная программа для Windows: на рабочем столе висит одна стеклянная колба с прозрачным фоном. Друг играет на басу, каждая нота вливается в колбу живой краской. Басовые приёмы варят особые жидкости. Закупоренное зелье застывает в головку сыра с разводами на срезе, сыр ложится на полку как пластинка, а по нажатию плавится в колбе и проигрывает запись.

Короткое название везде: **Басовое космическое сыроварение**.

## Как устроено

- `index.html`: вся программа (HTML + Canvas 2D + WebGL2), работает и в браузере.
- `main.js`: Electron. Прозрачное окно без рамки, разрешение на звук и MIDI выдаётся автоматически.
- `package.json`: `npm install`, `npm start`; сборка в один `.exe` через `npm run dist` (electron-builder, цель portable).
- Данные (полка, книга жидкостей, настройки) хранятся в localStorage окна.

## Петля игры

1. Играешь, зелье варится в колбе.
2. «Закупорить»: зелье застывает в головку сыра, показывается срез с разводами из колбы. Паузы в игре становятся дырками.
3. Сыр ложится на полку, головки стоят как пластинки.
4. Нажатие на сыр: он падает в колбу, плавится, и запись проигрывается заново, вместе с записанным звуком баса.

## Этапы

Состояние: все четыре этапа готовы.

### 1. Чистый вид: только колба ✓
- По умолчанию видна одна колба. В Electron фон прозрачный, в браузере тёмный ночной градиент.
- Панель управления появляется при движении мыши и прячется через 2,5 с. Гриф виден только в режиме виртуального баса.
- Колба: круглодонная, стекло с толщиной, отогнутый край-тор, блики с одной стороны, мягкая тень под колбой. Без подставки, планеты, колец и лун в базовом виде.
- Жидкость:
  - воды нет: колба начинается пустой, жидкость появляется только из нот и приёмов и наполняет круглое дно по площади, так что первые ноты сразу дают лужицу;
  - у каждого зелья палитра из 5 сочетающихся цветов; нота выбирает цвет по кварто-квинтовому кругу внутри палитры, поэтому смеси не уходят в бурое;
  - медленное плавное перемешивание, чёткие разводы, без мутного свечения;
  - перламутр только как тонкий отлив на гребнях.
- 3D: колба — тело вращения, жидкость рендерится лучами через настоящий объём шара и горлышка. Двумерная симуляция — срез по оси: точка объёма читает его, повернувшись на угол колбы, а под зеркалом срез читается глубже к центру, поэтому сверху видны разводы. Колбу крутят мышью или пальцем (по горизонтали — поворот, по вертикали — наклон), у неё есть инерция и медленный дрейф. На стекле вытравлены шкала и звёздочка, они поворачиваются вместе с колбой. Нерпа и выдры плавают вокруг оси. Сыр нарисован объёмной головкой с вынутым клином.
- Струя в горлышке: толщина зависит от силы удара (гост — нитка, слэп — толстая), пока нота держится, струя набухает; трюк даёт плотный выплеск. Каждая короткая нота падает каплей, длина и толщина которой зависят от силы.
- Перелив, вариант В:
  - обычная игра: тонкие полупрозрачные капли медленно сползают по стеклу с мокрыми дорожками;
  - громкая или быстрая игра: зелье переваливает через край горлышка и стекает по стеклу ручейками вокруг всей колбы (они поворачиваются вместе с ней), стекло покрывается тонкой плёнкой, внизу с ручейков срываются капли в лужицу. Струи-дуги нет;
  - лужица — плоский эллипс у основания, растёт с объёмом, рябь от падений. Ничего не исчезает.

### 2. Вход и запись ✓
- Автоопределение: после разрешения на звук программа перебирает входы, предпочитает названия звуковых карт (Focusrite, Scarlett, Behringer, UMC, Steinberg, iRig, Guitar Link, USB Audio, Line In) и слушает сигнал. Устойчивые ноты 30–400 Гц означают «бас найден». Подключение и отключение ловятся событием `devicechange`. MIDI определяется само.
- Со звуковым входом и MIDI программа сама ничего не играет. Синтезатор звучит только у виртуального грифа.
- Запись: события нот с метками времени плюс аудиодорожка входа (MediaRecorder). Дорожка сохраняется в IndexedDB, чтобы пережить перезапуск.

- Сделано так:
  - Захват идёт в AudioWorklet блоками по 1024 сэмпла, поэтому медленный кадр не теряет звук.
  - Высота ноты определяется методом YIN по окну около 85 мс, сигнал прорежен до ~11 кГц, диапазон 29–420 Гц. Нижнюю си (31 Гц) программа тоже слышит.
  - Начало ноты — скачок уровня. Нота засчитывается, когда две оценки высоты совпали.
  - Сила удара считается от громкости относительно недавнего максимума: тише на 15 дБ и больше — гост. Слэп — резкий яркий щелчок в начале ноты.
  - Слайды и хаммер-оны — смена высоты без нового щипка.
  - Порог тишины подстраивается под шум входа.
  - На синтетическом басе (обычная нота, гост, слэп, слайд на 8 полутонов, повторный щипок, нижняя си) все ноты распознаются верно.
- Звук пишется в 22 кГц / 16 бит, с полсекундой до первой ноты. Хранится в IndexedDB, при плавке сыра проигрывается вместе с нотами (сдвиг на 70 мс на задержку распознавания), при «×2» темп ускоряется без изменения высоты. Синтезатор при проигрывании звучит только для нот, у которых нет своего звука: виртуальный гриф, автоигра, MIDI без записи.

### 3. Сыр и полка ✓
- При закупорке текстура краски из колбы снимается и накладывается на срез сырной головки: круг с вырезанным клином, на срезе мраморные разводы, корочка по краю, дырки от пауз.
- Полка: головки сыра в ряд как пластинки, подпись — название зелья и длительность.
- Нажатие: сыр падает в колбу, плавится (растворяется в жидкость), запускается проигрывание событий и аудиодорожки. Можно ускорить вдвое, остановить, доварить.
- Сделано так: запись идёт с первой ноты после закупорки или «Вылить». Полка хранится в localStorage (ноты, срез JPEG 160 px, дырки). Записи с виртуального грифа и автоигры проигрываются синтезатором; у записей со звукового входа (этап 2) будет своя аудиодорожка, синтезатор для них молчит. «Доварить» продолжает запись с текущего места, старый сыр остаётся на полке.

### 4. Настольное приложение ✓
- `BrowserWindow`: `transparent: true`, `frame: false`, `hasShadow: false`, `backgroundColor: '#00000000'`.
- Перетаскивание за горлышко колбы (зона `-webkit-app-region: drag`).
- Пункты в панели: «Поверх всех окон», «Свернуть», «Закрыть».
- `session.setPermissionRequestHandler` разрешает `media` и `midi` без вопросов.

## Как запустить

```
cd basovoe-syrovarenie
npm install
npm start
```

Собрать один `.exe`: `npm run dist`, файл появится в папке `dist`.
