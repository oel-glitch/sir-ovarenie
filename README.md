# Басовое космическое сыроварение

Подарок другу-басисту: на рабочем столе Windows висит стеклянная колба с прозрачным фоном. Каждая сыгранная на басу нота вливается в колбу живой краской, басовые приёмы варят особые жидкости, а закупоренное зелье застывает в головку сыра.

Подробный план и книга жидкостей — в [PLAN.md](PLAN.md).

## Запуск

Нужен [Node.js](https://nodejs.org/) 20+.

```
npm install
npm start
```

`index.html` работает и просто в браузере (без прозрачного окна): его можно открыть двойным щелчком.

## Сборка .exe

```
npm run dist
```

Файл появится в папке `dist`. Его же собирает GitHub Actions на каждый пуш в `main`: вкладка **Actions → build → Artifacts → basovoe-syrovarenie-exe**.

## Как пользоваться

- Наведи мышь на колбу — сверху появится панель, через 2,5 с она спрячется.
- Колбу можно перетаскивать за панель. Пустые места окна пропускают клики на рабочий стол.
- «Виртуальный бас» открывает гриф: играть мышью, тачем или с клавиатуры.
- «Автоигра» сама играет приёмы, чтобы посмотреть жидкости.
- «Книга жидкостей» показывает, какие из 17 жидкостей уже открыты.
- «Поверх окон» держит колбу над всеми окнами.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | Вся программа: HTML + Canvas 2D + WebGL2 |
| `main.js` | Electron: прозрачное окно без рамки, автоматическое разрешение на звук и MIDI |
| `preload.js` | Мост между страницей и окном (сквозные клики, поверх окон, свернуть, закрыть) |
| `PLAN.md` | План по этапам |
