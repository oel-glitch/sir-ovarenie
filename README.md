# Басовое космическое сыроварение

Подарок другу-басисту: на рабочем столе Windows висит стеклянная колба с прозрачным фоном. Каждая сыгранная на басу нота вливается в колбу живой краской, басовые приёмы варят особые жидкости, а закупоренное зелье застывает в головку сыра.

Подробный план и книга жидкостей — в [PLAN.md](PLAN.md).

## Скачать готовую программу

[Basovoe-syrovarenie.exe](https://github.com/oel-glitch/sir-ovarenie/releases/latest/download/Basovoe-syrovarenie.exe) — один файл для Windows, ничего устанавливать не нужно. Инструкция для того, кто получит программу в подарок: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

GitHub Actions собирает .exe на каждый пуш в `main` и выкладывает его в [релизы](https://github.com/oel-glitch/sir-ovarenie/releases). Ссылка выше всегда ведёт на последнюю сборку. Собрать вручную можно на вкладке **Actions → build → Run workflow**.

## Собрать на своём ПК

Дважды щёлкнуть `build-windows.bat`. Если Node.js не установлен, откроется nodejs.org: установить версию LTS и запустить файл снова. Готовый `Basovoe-syrovarenie.exe` появится в папке `dist`.

То же из терминала:

```
npm install
npm start       # запустить без сборки
npm run dist    # собрать .exe в папку dist
```

`index.html` работает и просто в браузере, без прозрачного окна.

## Как пользоваться

- «Бас: …» подключает настоящий бас через звуковую карту или микрофон. Программа сама находит вход, на котором слышен бас, и показывает тюнер. MIDI-устройства подключаются сами.
- Колба объёмная: тяни её мышью или пальцем, чтобы покрутить и наклонить. Отпущенная, она докручивается по инерции и медленно поворачивается сама. Shift + перетаскивание (или правая кнопка мыши) перемешивает зелье.
- Наведи мышь на колбу — сверху появится панель, через 2,5 с она спрячется.
- Колбу можно перетаскивать за панель. Пустые места окна пропускают клики на рабочий стол.
- «Виртуальный бас» открывает гриф: играть мышью, тачем или с клавиатуры.
- «Автоигра» сама играет приёмы, чтобы посмотреть жидкости.
- «Закупорить» превращает сваренное зелье в головку сыра: на срезе разводы из колбы, паузы в игре становятся дырками. Сыр ложится на полку внизу.
- Нажми на сыр на полке: он упадёт в колбу, расплавится, и запись сыграет заново. Во время проигрывания можно ускорить вдвое, остановить или «доварить» — продолжить играть поверх и закупорить новый сыр.
- «Вылить» сбрасывает зелье вместе с записью и меняет палитру.
- «Книга жидкостей» показывает, какие из 17 жидкостей уже открыты.
- «Поверх окон» держит колбу над всеми окнами.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | Вся программа: HTML + Canvas 2D + WebGL2 |
| `main.js` | Electron: прозрачное окно без рамки, автоматическое разрешение на звук и MIDI |
| `preload.js` | Мост между страницей и окном (сквозные клики, поверх окон, свернуть, закрыть) |
| `PLAN.md` | План по этапам |
| `icon.png` | Иконка программы |
| `build-windows.bat` | Сборка .exe двойным щелчком |
| `ИНСТРУКЦИЯ.md` | Инструкция для получателя, она же текст релиза |
